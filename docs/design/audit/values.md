Checkout `698034b`, release binary `audit/bin/objectflow-service` (objectflow-core 0.2.0). Every "reproduced" item below was run on that binary; the ten most severe are re-run by one script, `a3/repro/repro.py <sandbox port>`, whose modules both checkers accept (verified: `check-flows.py` in process and the core's checker through a sandbox `publish` preview, which runs `crate::check::checked`, `publish.rs:386`). ## 1. How the area was enumerated, and why it is complete

**What V and K are made of.** V is "what the engine stores, derives and answers, a filter's matches included, is what `flow-format.md` and `declaration-syntax.md` define, and the same on the core and the reference runner; a value it cannot compute is refused, never answered wrong or as null" (ADR-0204:100). K is "a flow both checkers accept is one the engine runs" (ADR-0204:108). So the area is the product of three enumerations:

1. **Every construct of the language.** The parse tree's variants, `expr.rs:72-110`: `Num` (int, decimal), `Str`, `Bool`, `Dur`, `Money`, `Name`, `Path`, `Call`, `Agg` (the ten aggregates of `expr.rs:216-227`, comprehension and metric forms), `Metric`, `Changed`, `Set`, `Not`, `Neg`, `IsNull`, `In`, `Bin` (13 operators, `expr.rs:22-36`), `If`. Each name the evaluator resolves (`eval.rs:661-712`), each member (`eval.rs:715-858`), each function (`eval.rs:1374-1443`, `1528-1566`), and the metric language (`metric.rs`).
2. **Every kind of value** (`value.rs:392-436`) as the flow format's attribute types produce it (`flow-format.md` §4.3): int, decimal at three scales, money in three currencies of different minor units and one the core does not know, duration, timestamp, date, string, identity, bool, enumeration member, state, category, object, set, row.
3. **Every place an expression is evaluated**: a guard, an invariant, a derived attribute, a query filter (`reads.rs:1013-1031`), an aggregate's and a `foreach`'s `where`, an effect's `assign`, `add`, `create` and `call` argument, `foreach` array and range, a `default`, a migration `backfill`, and a metric's filter, dimension and value; and **every `not_run` site** of the core, found by `grep 'not_run(\|NotRun::Unsupported('`: `eval.rs` (45 sites), `request.rs` (38), `metric.rs` (35), `reads.rs` (10), `world.rs` (6), `import.rs` (2), `publish.rs`, `store.rs`, `model.rs` (the `beyond` list).

**How it was run.** A generator (`a3/py/gen.py`, `agg.py`, `met.py`) writes a module whose type holds one attribute of each kind and one derived attribute, invariant, condition or effect per expression; each module goes through (a) `scripts/check-flows.py`, (b) the core's checker, (c) the core's runtime in a sandbox, and (d) the reference runner `scripts/flowrun.py` through the Flow Studio server's `Sandbox` (`apps/flow-studio/server/flowstudio/sandbox.py`, run in process, loading unchecked as the core's sandbox does). The batteries, with their raw results in `a3/*.json`:

| Battery | Expressions | Result file |
|---|---|---|
| every binary operator over 21 operands of every kind (21 × 10 × 21) | 4,410 | `binops.json` |
| unary operators, `is null`, every name, `in` against 15 right sides, `if` over 12 branch pairs, 25 function names over 10 arguments, members | 1,018 | `misc.json` |
| aggregates over a value set, a reference set and a type scan, for every element kind, empty and with absent bodies | 178 | `agg.json` |

| metrics: 33 declared metrics and 30 metric expressions | 63 | run logs |

**Why this is complete.** Every `Expr` variant and every operator was evaluated over every value kind the wire can store; every place an expression is evaluated was exercised; and every `not_run` site was listed and either reached by a flow both checkers accept, shown refused by both checkers, or shown unreachable by construction (section 2.7). Across the probes, wherever a finding could be attributed to one expression, the two checkers agreed on all but the YAML edge of C2.

**Left out, and why.** An evaluator's verdict inside a larger expression (both checkers' check 24 rule was read, not probed); `over last` windows, `split_by` pieces and combined metrics (time arithmetic of spans, area 4's cost and the existing scenario suites); identifier `format` rendering (`request.rs:4242-4323`, read only); the import's value decoding (area 5); PostgreSQL (not built). The `Rat` comparison fallback (A4) is unconfirmed: I could not build values that reach it through the wire.

**What holds the area today.** The harness holds neither V nor K (`adversarial-harness.md` "Built": its conditions are §1's and A's and E's; `TODO.md:524` leaves "ADR-0204 §3's V against the reference runner" to a later slice). `checker_oracle.rs` holds the two checkers to each other over the plants of `check-flows.py`'s self-test. `apps/flow-studio/server/tests/test_backends_agree.py` holds the runner and the core to each other over the design's examples only. Unit tests hold single cases: `eval.rs` `unknown_propagates_but_through_is_null_and_or`, `arithmetic_keeps_its_types`, `a_type_scan_and_its_aggregates`; `value.rs` `rounding_drops_places_half_to_even`, `arithmetic_follows_the_scale_rules`; `request.rs` `a_date_moved_by_part_of_a_day_has_no_value` (9200) and `an_effects_arithmetic_past_its_bound_is_refused` (11391); `deployment.rs` `a_derived_time_past_the_calendar_has_no_value_in_a_query` (4584).

## 3. The broken items, most severe first

Each with the smallest fix and what it would refuse that 0.2.0 accepted (ADR-0204 §11).

1. **W1, blocker (V).** An int written to a `decimal(p,s)` attribute is stored divided by 10^s, by a default, a `set`, a `create` or `call` argument and a backfill. *Fix:* in `at_declared_scale` (`request.rs:397`) convert a `Value::Int` to the attribute's scale before the write, and make `to_sql` (`store.rs:1447`) take the declared type and refuse any value whose kind and scale are not the column's, so no route can write units of another scale. *Refuses nothing 0.2.0 accepted;* objects already holding a divided value need a repair the release notes must name (a store written by 0.2.0 may hold them; whether its log tells them apart from values written as such I did not establish).
2. **W4, blocker (V).** A quotient written to a wider decimal is rounded at the dividend's scale first. *Fix:* evaluate an effect's value written to a decimal with its quotient at the target's scale (pass the target's scale into the division, or compute the quotient exactly as a `Rat` and round once in `at_declared_scale`). *Refuses nothing;* it changes stored values from 0.2.0's, which the release notes name.
3. **W3, major (D, V).** A computed value of another type is written to any column: a currency relabelled, an amount rescaled, text into numbers, and a date or text into a time column bricking the object and its type's queries. *Fix:* `to_sql` refuses a value whose kind is not the column's (the request refused `value_in_range`, never written), and check 17 compares the type check 24 infers for a computed value with its target. *Refuses* flows 0.2.0 published with such writes (at publish), and the requests that would have written them.
4. **W2, major (V).** A decimal written to an int is stored multiplied by 10^s. *Fix:* the same two changes as W3. *Refuses* `set n := n * 1.5` into an int at publish.
5. **U1–U5, major (V; U3 and U4 also R).** Arithmetic with no value is answered `null` by a derivation, dropped from a query's, a loop's and a metric's matches, and holds in an invariant. *Fix:* read the evaluator's `failed_arithmetic` (`eval.rs:215`) at every place, as `effect_value` does (`request.rs:3774`): a `get`, a `query` or an `availability` whose derivation or filter sets it is refused `value_in_range` naming no value, an invariant that sets it refuses the request, and a metric whose filter sets it refuses the read; §8.2's table and `wire.md:44` rewritten to say so. *Refuses* reads and writes 0.2.0 answered (a derived value past its bound, a filter over such an object, a write an overflowing invariant let through); per ADR-0204 §11 these restore V and R.
6. **G1, major (V, R).** `any`, `none` and a non-distinct `count` ignore their body. *Fix:* treat a body as a further filter for those three (`eval.rs:1264-1277`, `1321-1325`, and the runner's `flowrun.py:1083-1098`), or refuse a body there in check 47. *Refuses,* if the second, flows 0.2.0 published with such a body; the first changes their answers.
7. **A3 (and A4 if reachable), major (V).** Decimals compared by sign when their scales cannot be aligned. *Fix:* compare by whole and fractional parts, or by a widening multiply, in `Decimal::cmp` (`value.rs:198`) and `Rat::cmp` (`rat.rs:101`). *Refuses nothing.*
8. **A1, major (V).** A decimal literal dividend keeps its written scale. *Fix:* give a literal the other operand's scale where §8.1 says it takes it (`eval.rs:2051`), as the metric evaluator already does. *Refuses nothing;* changes answers.
9. **G2, major (V).** `time_in` of a non-state answers `0 s`. *Fix:* both checkers apply check 58 to `time_in`'s argument in every place, and the evaluator answers `not run` for a name that is no state. *Refuses* such flows at publish.
10. **W5, L1, L2, major (V).** A plain write to a narrower decimal, a money literal past its minor unit and a fractional-second duration literal are rounded silently. *Fix:* check 17 refuses a scale-reducing plain write (§8.3's rule), and step 3 refuses the two literals. *Refuses* such flows at publish.
11. **K-1 to K-12, M2, W6, L4, L6, G9, minor (K).** About 700 constructs both checkers accept that the core refuses at run time, a whole type unusable under `inherited_parts`, a currency the core does not know making its attribute unwritable, and every metric expression untyped. *Fix, as a class:* one table of what the evaluator takes, each operator's and function's operand kinds and result kind, read by both checkers' typing (which today decides a rule "only where every operand it reads is known", `check-flows.py:2390-2393`) and refusing an operand of unknown type where the operator's table has no entry for it, with the metric language typed over its rows; and either `inherited_parts` built in the core or refused by both checkers. *Refuses* at publish the flows 0.2.0 published with these constructs, each of which 0.2.0 could not run.
12. **Minor, the rest:** A2 and A5 (the documents to state a literal's scale and a duration's rounding), G7, G8, R1–R9 (the runner brought to the core's scales and bounds), C2 (plants for both YAML edges).

**The checks to add, as the class's guard:** (a) the differential battery of this audit, its probe modules and expression lists (`a3/py`), made a gate: for every expression both checkers accept, the core must not answer `501` and must equal the reference runner; (b) the harness V condition of 2.8; (c) suite tests named in each row.
